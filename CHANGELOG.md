# Changelog
## 0.2.0 — 2026-11-27
**Fixed:** the Mac app received no call audio at all (wrong Core Audio key name). Live subtitles from system audio now work.
**Added:** hands-free interpreting, interpreted lines in the transcript, Both/Translation/Original display, live transcript panel, language summary, voice and microphone pickers, Personal Voice, setup checklist, word list, notes language, echo filter.
**Extension:** single recogniser per call, "Caption this tab", visible error messages.

## 0.1.0 — 2026-11-24
First build: menu-bar app with live subtitles (Apple SpeechAnalyzer / WhisperKit), language ID, translation chain, interpretation via BlackHole, meeting records, search, export (MD/SRT/DOCX), notes with Pull the Thread, Privacy Ledger, onboarding, settings, localisation scaffold, website, packaging scripts.
Known limitations are listed in the README and docs/PROGRESS.md.
